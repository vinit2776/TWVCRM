# Inventory Module — Onboarding Checklist

Use this checklist to onboard a new team member onto the **Inventory / Transfers / Consumption** module. Pair it with the [full training guide](./inventory-transfers-consumption.md).

**How to use:** the trainer (admin/manager) sits with the new user, works top to bottom, and ticks each box once the user has *done it themselves* — not just watched.

---

## A. Before you start (admin/manager sets up)

- [ ] User has a TWV CRM login and can sign in.
- [ ] User's **role** is set correctly (see role table in the training guide).
- [ ] User is assigned to the right **location(s)**.
- [ ] Confirm which flows this person needs: **Consumption only**, **Transfers**, **Approvals/Corrections**, or all.

---

## B. Everyone — orientation (15 min)

- [ ] Find **Procurement** in the left sidebar and open **Inventory**, **Transfers**, **Consumption**.
- [ ] In **Inventory**, select their location and read the table (Qty on Hand, Reorder Level, Status badge).
- [ ] Understand the golden rule: *if a number looks wrong, a consumption or transfer probably wasn't logged.*
- [ ] Know where stock comes from (POs, transfers in) and where it goes (consumption, transfers out).

---

## C. Floor staff / FMS — logging consumption (most common)

- [ ] Open **Consumption** and switch language if needed (English / தமிழ்).
- [ ] Step 1: select the correct **location**.
- [ ] Step 2: search an item, set a quantity with **– / +**, add 2–3 items to the cart.
- [ ] Understand that *only items with stock at that location appear*.
- [ ] Step 3: review the cart; add a note.
- [ ] Step 4: **Submit** and see the success screen.
- [ ] Re-open **Inventory** and confirm the stock dropped by what was logged.
- [ ] See a **reorder alert** at least once (log enough of a low item) so they recognise it.

---

## D. Store / dispatch staff — running a transfer

- [ ] **Create** a transfer: pick From + To locations, add items + quantities (Draft).
- [ ] **Submit for approval** and watch the status change to *Pending Approval*.
- [ ] Read the **Transfer progress** bar at the top — know what each stage means.
- [ ] After approval, **Mark Dispatched** and confirm stock left the *From* location.
- [ ] Open the transfer at the destination and **Receive** it; enter quantities received.
- [ ] Practice a **partial receive** and then **Report an Issue** (shortage) so they know the path.
- [ ] **Download the Challan** PDF and check it lists the items.

---

## E. Manager / admin — approvals, issues, corrections

- [ ] Open a *Pending Approval* transfer, review the **Stock Levels for Approval** table.
- [ ] **Approve** one and **Reject** one (with a reason) — see the reject reason appear on the transfer.
- [ ] **Resolve an Issue** on a transfer, including the "adjust stock for shortage" option.
- [ ] In **Consumption → History**, open a log and run each correction once:
  - [ ] **Void** (restores all stock)
  - [ ] **Adjust** (change one item's quantity)
  - [ ] **Re-log** (void + create a corrected entry)
- [ ] Confirm the correction shows in the log's history with the reason and your name.

---

## F. Sign-off

- [ ] User can complete their core task **unassisted**.
- [ ] User knows **who to contact** when a number looks wrong or an action is blocked.
- [ ] Trainer name: ______________  Date: ____________
- [ ] New user name: ____________  Role: ____________

> Keep this checklist with the new user for their first week. Anything that felt confusing → tell the admin team so the training guide can be improved.
